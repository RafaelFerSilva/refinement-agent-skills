# US-231: Exportar relatórios em PDF

Status: aberta
Azure: 231

Como usuário, quero exportar os relatórios em PDF para facilitar o compartilhamento.

Critérios de aceite:

- AC1: O botão de exportar deve funcionar corretamente.
- AC2: Criar o serviço de geração de PDF no backend.
- AC3: O PDF deve abrir rápido.
- AC4: Código revisado e testes passando.
