# US-245: Silenciar alertas de um veículo

Status: aberta
Azure: 245

Como usuário, quero silenciar os alertas de velocidade de um veículo por um tempo, para não ser incomodado quando já estou tratando o caso.

Critérios de aceite:

- AC1: O usuário consegue silenciar o veículo de forma simples.
- AC2: Ajustar a tabela de alertas para guardar o silenciamento.
- AC3: Os alertas voltam sozinhos depois.
- AC4: Testado em homologação.
