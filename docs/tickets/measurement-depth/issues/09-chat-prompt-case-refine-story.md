# 09: Eval case against the generated chat prompt

Status: resolved
Blocked by: none
Type: task
Origin: 2026-10-25 (commit 81547f6)

`prompts/` is a product: the chat version of every workflow, generated from `skills/` by around thirty live adaptation rules. No eval has ever executed one. The validator only checks that the file matches what the build would produce, so a rule that adapts wrongly produces a stable, wrong prompt and passes.

Run `prompts/refine-story.md` as the whole instruction, with the User Story and glossary fixtures pasted rather than read from disk, and assert the behavior that the adaptation is supposed to preserve in Round 1: the same triage, a round in the same shape waiting for the PO without synthesizing early, and no reference to writing files, `.scratch/`, operating modes, or subagents that do not exist in a chat (synthesis delivery in titled chat blocks is covered by ticket 10).

## Acceptance criteria

- A case in `evals/refine-story.json` declares `prompts/refine-story.md` as its instruction rather than the skill, with the `us-245-silence-alerts.md` and `CONTEXT-fleet.md` fixture content inline and no workspace configuration fixture.
- Its assertions cover: triage stated, Round 1 in the `socratic-examination` shape waiting for the PO without synthesizing the refined User Story, no reference to writing files or to `.scratch/`, and no mention of an operating mode or a subagent that the chat version removes.
- The case is run and its result recorded over the 5-run / 80% threshold convention in `evals/README.md`.
