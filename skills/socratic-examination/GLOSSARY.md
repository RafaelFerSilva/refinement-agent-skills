# CONTEXT.md Format

```md
# <Product or context name>

<One or two sentences explaining what this context is and why it exists.>

## Language

**Term**:
<One or two sentences: what the term is, not what it does.>
_Avoid_: <synonyms not used in this product>
```

Rules:

- Be opinionated. When multiple terms exist for the same concept, select the best and list alternatives under _Avoid_.
- Concise definitions: one or two sentences.
- Only terms belonging to this product domain. General software concepts do not belong, even if widely used in the product.
- Group under subheadings when natural clusters emerge; flat list otherwise.
- Create the file the first time a term is resolved, not before.
